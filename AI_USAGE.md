# AI Usage Documentation – JollyRx Platform

This document describes how Artificial Intelligence tools were utilized during the development, integration, and testing of the JollyRx B2B Contract Development and Manufacturing Organization (CDMO) prototype.

---

## 1. Overview of AI Assistance

- **Tool Used:** Antigravity (Powered by DeepMind Gemini)
- **Role:** Technical assistant supporting architecture design, Deluge scripting, backend proxy development, frontend RFQ form styling, and integration debugging.

All suggestions and code generated by AI were reviewed, adapted, tested, and verified against the live Zoho platforms and local test suites.

---

## 2. Key Areas Where AI Assisted

1. **Architecture & Masked Model Design:**
   - Assisted in designing the data boundary ensuring private plant records (legal name, physical factory address, drug license) reside solely in Zoho Creator.
   - Recommended exposing only masked identifiers (`NODE-GJ-01`, `NODE-MH-02`, `NODE-MP-03`) on the Zoho Commerce storefront.

2. **Frontend RFQ Embed Component:**
   - Generated the scoped HTML, responsive CSS, and JavaScript for the B2B quote request form.
   - Added client-side email format validation, batch quantity checks, URL pre-fill (`?node=...`), and a honeypot field (`company_fax`) to mitigate automated spam.

3. **Backend Ingestion Proxy (Express):**
   - Provided the initial Express proxy structure (`server/server.js`) to keep the Zoho Flow webhook URL and zapikey securely on the server side.
   - Implemented request validation, rate limiting (10 requests/minute per IP), and silent honeypot filtering.

4. **Zoho Flow & Creator Deluge Debugging:**
   - Diagnosed Zoho Creator validation error 3001 (Requested Quantity exceeding default digit limits) and guided setting Max Digits to 10.
   - Diagnosed payload nesting issues where an outer `payload` wrapper caused Flow variable lookups to evaluate to null; restructured inbound requests to flat JSON.
   - Assisted with the Deluge script (`Populate RFQ Data on Create`) to automatically look up parent plant attributes and populate Product Molecule, Dosage Form, and Inquiry Date.

5. **Documentation & Testing:**
   - Drafted the API test suite (`tests/api_test.http`) covering positive submissions and input validation edge cases.
   - Helped format technical documentation and the 3-minute video presentation script.

---

## 3. Human Review & Verification

All AI-assisted outputs underwent manual validation:
- Zoho Creator forms and Deluge scripts were configured, tested, and confirmed in the live Creator workspace.
- The Zoho Flow bridge was inspected in execution history to verify all three steps (`Webhook → Fetch Record → Create Record`).
- Submissions were verified end-to-end against actual database records created in Zoho Creator `RFQ_Inquiries`.
